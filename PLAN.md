# Mova — план розробки

> Джерело: нотатка Notion [«Застосунок для вивчення мов — ідея та план»](https://app.notion.com/p/3fa0e16f846581e8abc3fa4af54e3a38).
> Мобільний застосунок: голосові розмови з ШІ за темою й рівнем + граматика на основі реальних помилок.
> Перша мова: англійська для україномовних. Російська не підтримується ніде.

## Стек

- **Мобільний застосунок:** React Native (Expo)
- **Бекенд:** Supabase (Postgres, Auth Apple/Google, Edge Functions)
- **ШІ:** Claude API — Haiku 5.5 для Free та A1–B1, Sonnet 5.5 для B2+ і Pro
- **STT:** вбудоване розпізнавання пристрою / Whisper
- **TTS:** gpt-4o-mini-tts / ElevenLabs / Google
- **Підписки:** RevenueCat

**Принцип:** жодних ключів у застосунку, усі виклики ШІ через Edge Functions; ліміти перевіряються на сервері.

## Етап 2. Голосовий діалог — ядро MVP (2–3 тижні)

- [ ] Edge Function `conversation-start`: перевірка ліміту → створення розмови → перша репліка ШІ + TTS
- [ ] Edge Function `conversation-turn`: аудіо → STT → Claude → TTS (streaming), запис `messages` і `usage_events`; аудіо не зберігати
- [ ] Edge Function `conversation-finish`: `feedback_reports`, `mistakes` (категорії articles / tenses / word_order / prepositions / vocabulary, пояснення українською), пропозиції слів для повторення
- [ ] Системні промпти: репетитор Emma, рівень CEFR, короткі репліки, підказки українською на A1–A2, типові помилки україномовних; кешування промпту
- [ ] Вибір моделі за тарифом і рівнем
- [ ] Заміри затримки повного циклу; ціль — природна розмова без пауз

## Етап 3. Мобільний застосунок: екрани етапу 1 (2–3 тижні)

- [x] Каркас RN: навігація (Головна, Профіль), темна тема з токенами (фон `#0E1014`, картки `#171A21`, акцент `#5EE0B8`, помилки `#F2B880`, шрифт Onest), i18n uk/en
- [ ] Онбординг (2–3 слайди) → вхід Apple/Google → вибір мови й рівня → дозвіл на мікрофон
- [ ] Головна: «Почати розмову» + рекомендована тема, залишок хвилин, серія днів, хвилини за тиждень, останні розмови, 3–4 бейджі; чіп мови в шапці (EN · B1)
- [ ] Вибір теми й рівня (+ власна тема)
- [ ] Екран розмови: «натисни і говори», стани слухає / думає / говорить, кільце залишку хвилин, субтитри (увімкнені на A1–A2), переклад слова дотиком, «Підказка», «Завершити»
- [ ] Підсумок: помилки «було → стало», нові слова, «Зберегти слова»
- [ ] Профіль: мої мови, мова інтерфейсу, рівень, тариф, використані хвилини, вихід, видалення акаунта

## Ризики
